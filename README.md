# Nexo360

**Nombre del proyecto:** Nexo360: Plataforma web accesible de orientación y centralización de trámites y servicios digitales de Duoc UC.

**Descripción:**  
Nexo360 es una plataforma web accesible orientada a facilitar la experiencia académica digital de estudiantes pertenecientes a PAEDIS de Duoc UC. Busca centralizar y organizar información, orientación y accesos relacionados con trámites y servicios digitales que actualmente se encuentran distribuidos en distintas plataformas y canales, reduciendo barreras de navegación, comprensión y acceso para estudiantes con diferentes necesidades de accesibilidad.

**Arquitectura de la solución (descripción o diagrama):**  
La arquitectura de Nexo360 se encuentra en etapa de definición. Su diseño considerará la recopilación y organización de información proveniente de distintas fuentes digitales, incluyendo mecanismos de web scraping cuando corresponda, además de los componentes necesarios para presentar esta información mediante una plataforma web accesible, segura y mantenible.

**Instrucciones para ejecutar el proyecto localmente:** Se incorporarán durante la fase de desarrollo una vez definida la arquitectura y las tecnologías de implementación.

**Arquitectura de la solución (descripción o diagrama):** Por definir durante la fase de diseño técnico, una vez revisados los requerimientos, restricciones institucionales y tecnologías disponibles.
