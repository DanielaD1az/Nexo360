# Nexo360

## Descripción

Nexo360 es una plataforma web accesible orientada a facilitar la experiencia académica digital y favorecer la autonomía de los estudiantes pertenecientes a PAEDIS de Duoc UC.

La plataforma busca reunir y organizar en un mismo entorno información, orientación y accesos a trámites y servicios digitales institucionales, permitiendo que los estudiantes puedan identificar qué gestión necesitan realizar, comprender sus requisitos y pasos, y acceder posteriormente al servicio correspondiente.

El proyecto está dirigido principalmente a estudiantes PAEDIS, considerando distintas necesidades de accesibilidad visual, motora y cognitiva.

Nexo360 busca disminuir las barreras que pueden presentarse actualmente al buscar información, comprender procedimientos o identificar dónde realizar una gestión cuando los servicios se encuentran distribuidos entre diferentes plataformas y canales institucionales.

## Metodología de trabajo

Nexo360 será desarrollado mediante una metodología ágil basada en **Scrum**, adaptada a un equipo de dos integrantes.

El trabajo se organizará mediante un **Product Backlog** priorizado y sprints principalmente de una semana.

El proceso contempla:

- Levantamiento y análisis de requerimientos.
- Priorización del Product Backlog.
- Diseño y prototipado.
- Desarrollo incremental.
- Revisión del avance al finalizar cada sprint.
- Pruebas funcionales, técnicas y de accesibilidad.
- Validaciones con usuarios.
- Incorporación de mejoras a partir de la retroalimentación obtenida.

GitHub será utilizado para control de versiones y trabajo colaborativo.
