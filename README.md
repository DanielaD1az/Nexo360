# Nexo 360

## Descripción

Nexo 360 es una plataforma web accesible orientada a centralizar y facilitar el acceso a trámites y servicios digitales para estudiantes de Duoc UC.

El proyecto busca reducir las barreras que enfrentan los estudiantes al tener que navegar entre distintas plataformas, sitios y canales institucionales para realizar solicitudes o encontrar información relevante.

La solución será diseñada considerando criterios de accesibilidad para personas ciegas, con baja visión, neurodivergentes y otros estudiantes que puedan enfrentar dificultades de navegación o comprensión en entornos digitales.
